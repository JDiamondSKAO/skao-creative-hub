Where should I look for presentations?

Start with presentation resources. Released decks belong in the Hub. A page description is not a file download.

Why can I browse but not upload?

Browsing, downloading and contributing can have different permissions. Ask for the appropriate contribution route rather than treating a library link as an upload form.

Is my request booked once submitted?

No. The team confirms scope, capacity and delivery timing after review. Read how timing is agreed.
