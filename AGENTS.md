# Working on the SKAO Creative Hub (for AI coding assistants)

Read [HANDOVER.md](HANDOVER.md) first for the current state and next steps, then [README.md](README.md) for how the project fits together.

## Hard rules

- **This repository is public.** Never commit internal links, credentials, tokens, personal names or staff photos.
  - Internal document links go only in the local `dev/links.json`. Their names are listed in `scripts/links.py`.
  - Credentials stay in the local `dev/canto.env`. Never print, copy or commit its contents.
  - Never ask anyone to paste a token into a chat. The scripts ask for tokens in the terminal.
- **Edit the sources, not the output.** `page.vm` and `docs/` are generated by `python3 scripts/build.py`. Change `scripts/*.py`, `js/main.js` or `css/style.css`, then rebuild.
- **Tests must pass:** `node scripts/test.cjs` (or `npm test`). Check the exit code, not only the last line of output.
- **Never publish a release zip.** `release/` holds builds with internal links filled in.
- **Destructive Confluence or GitHub actions need the owner's explicit OK.** That includes deleting pages, attachments, branches or tables. The Confluence tools only move pages to the trash and never purge it.

## How the build works

- `scripts/build.py` runs the layers in order: `journeys.py` (homepage), `interiors.py` (every page and its route), `slidekit.py` (Slide deck and template), `sharekit.py` (Share your presentation), `polish.py` (sections, menus, search and All files), `gethelp.py` (Common questions, moved pages, search answers) and `brandkit.py` (download groups).
- **Sections and menus** come from `SECTIONS` in `polish.py`. A section can be hidden without deleting it: `HIDDEN_SECTIONS`, which hides Events for now.
- **Pages created after the first release** have stand-in IDs in `interiors.PLANNED`. They're matched by title on the live site, ignoring capitals, and linked through the site's own page tree (`#hubRoutes`).
- **The live site adds Confluence's own CSS**, which reaches headings, buttons and boxes. Pin layout-critical spacing (with `!important` where needed). Check changes by injecting extra CSS in the browser as well as in local test mode.

## Checking your work

- Static preview: serve `docs/` on port 8766.
- **Local test mode** (`scripts/dev_fixtures.py`, then `scripts/dev_server.py` on port 8767) simulates Confluence: downloads, search, Just added, the Canto slideshow and the announcement bar. Add `?fresh` for a first-time visitor. Restart the server after adding a new link name.
- Check pages at a desktop width (about 1500 px) and on a phone, in light and dark mode.

## Releasing

1. Bump the version in `scripts/package.py` and add a `CHANGELOG.md` entry in plain English.
2. Run `python3 scripts/package.py`.
3. Copy the new flat zip and its nine files into `release/go-live/theme/` for upload.
4. Commit, push, and tag the release (`vX.Y.Z`). `main` is the live release.

## Writing style

- Plain, warm British English, the way the Communications team speaks: "we", short sentences, no marketing language.
- SKAO house style:
  - it's the "SKAO slide deck", never "master deck";
  - spell out "Square Kilometre Array Observatory" where it fits;
  - no em dashes or ampersands in copy;
  - write "for example" rather than "e.g.".
- Never use tick-list checklists in the Hub. Use short numbered or described steps.
- Don't name individual staff in the Hub or this repository. Say "the Communications team".
